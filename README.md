# um recadinho pra você ☁️

Uma página simples, divertida e levemente romântica — com humor e sem declaração explícita.

## Como abrir
1. Baixe os três arquivos (`index.html`, `style.css` e `script.js`) para a mesma pasta.
2. Abra `index.html` no navegador.

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os três arquivos para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
6. Aguarde o link do site aparecer na seção Pages.

Não precisa de servidor nem instalação. A fonte do Google Fonts usa internet; o site continua funcionando sem ela, com fontes alternativas.
